# 📊 Power BI Analytics & Dashboards Portfolio

Welcome to my Power BI portfolio repository! This collection features interactive dashboards, data models, and reports created during my Power BI certification and analytical projects. 

These projects showcase end-to-end data analytics workflows—from data extraction, transformation (Power Query), and semantic modeling, to advanced DAX calculations and interactive visual design.

---

## 🛠️ Skills & Technologies Demonstrated

* **Data Transformation & Modeling:** Power Query, ETL pipelines, Star Schema / Snowflake Schema design, Semantic Modeling.
* **Calculations & Logic:** Advanced DAX (Time Intelligence, Iterators, Custom Measures & Calculated Columns).
* **Visualization & UX:** Custom theme styling, interactive bookmarks, drill-through pages, tooltip pages, dynamic filtering.
* **AI & Advanced Features:** Key Influencers, Decomposition Trees, Q&A visuals, and geospatial mapping.
